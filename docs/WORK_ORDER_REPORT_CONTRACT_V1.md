# ServiceScribe 工单到车辆维修历史契约 v1

状态：2026-10-01 冻结，作为 `haoqi` 分支的实现与验收依据。

## 目标与权威边界

本轮交付一条可实际操作的流程：manager 上传并审核报告模版及字段规则；开工前可上传工单；技工选择工单和模版，现场口述或输入；系统按字段清单提取、发现缺口并立即追问；技工复核确认；报告按车辆归档并可导出。没有工单时仍可开始维修报告。

本轮只处理本系统内的工单和维修历史。SBS Transit 的 BEAMS、MaxiMobility 或其他内部系统没有已获授权的接口、字段定义或真实凭据；不宣称已连接或回写。导出结构保留将来的对接能力。SBS Transit 名称与样例数据均不能表示官方部署或真实车辆事实。

Manager 决定字段是否必填、何时必填、允许来源、类型、允许的明确“无”或“不适用”状态，以及是否必须技工确认。LLM 可以提出模版字段和规则草案，但草案未经 manager 审核不能发布为有效规则。系统与 LLM 都不能自行把可选项升级为必填，或把知识库文字升级为本次作业事实。

## 数据契约

- `TemplateField`: 稳定字段 ID、标签、章节与顺序、类型、`required`、可选的 `requiredWhen`、允许来源、关键性、确认规则、模版版本。每个已发布模版拥有冻结的字段清单。
- `WorkOrder`: 工单 ID、文件与哈希、来源/上传者/时间、提取候选、经人工核对的车辆 ID 与已知任务字段、状态和版本。无法可靠识别车辆时保持待核对，不按模糊匹配写入车辆历史。
- `ReportSession`: 绑定准确的模版版本、可选工单版本、车辆 ID，以及原始音频/转录、复核决定、字段候选、来源片段、追问答案、验证与确认记录。
- `VehicleHistory`: 用经核对的稳定车辆 ID 关联多个已确认报告；每条记录保留工单 ID、报告版本、确认时间、技工和可追溯快照。历史不得用车牌、型号或 LLM 猜测的文本自动合并。

字段允许来源按业务意义区分：`TECHNICIAN` 为本次口述、文字输入与技工确认；`WORK_ORDER` 为本次经核对的工单资料；`KNOWLEDGE` 为模版绑定的知识库规范/术语。LLM 在允许范围内提出字段来源和候选值，服务器根据字段规则、证据和验证结果决定字段状态。知识库可提供规范性内容、术语修正和问题提示；不能单独证明本次实际完成的操作、零件、测量、测试、故障结论、安全或恢复运行状态。

字段状态至少保留：未知、已取得有依据值、待确认、冲突、无效、明确无、不适用。沉默不得变成“正常”“已完成”或“没有更换”。条件字段的触发依据只能是经核对的本次事实或明确技工回答。例如 manager 可设“是否更换零件”为必答，且“零件明细”只在回答“是”后必填；未知时先问是否更换，不能猜。

## 用户流程

1. Manager 上传文本可解析的模版，查看系统提议的字段清单，增删改字段并设置规则；非文本或无法可靠解析时明确进入人工定义流程。模版发布后版本不可原地改变。
2. Manager 或获授权的人员可在开工前上传工单。系统提取工单号、车辆 ID 和已知任务字段，展示来源供人核对；通过核对后工单才可用于权威预填。
3. 技工选择工单（可跳过）与已发布模版。系统在录音前生成该模版完整的结构化字段清单，已有工单值只填允许由 `WORK_ORDER` 提供的字段。
4. 保存不可变原始转录。LLM 可提出转录修改，实质性修改（型号、编号、数字/单位、否定、完成或安全状态）需要技工确认；从复核后的文字提取带原文片段的字段候选。
5. 系统对每个字段运行来源、条件必填、冲突、类型和安全验证。处理完当前一次口述/输入后立即展示缺口并给出具体追问；回答进入同一证据链，再重新验证。假设 20 项中 8 项经规则判定需要技工本次叙述，最终仅有 6 项得到有依据值，界面立即指出剩余 2 项并要求补充，不用知识库补猜。
6. 无阻塞项后技工复核并确认报告。确认后的快照不可覆盖；导出及车辆历史均读取同一快照。若保存或外部交付失败，应明确显示状态，不能假称已完成同步。

## 质量门槛与非目标

每批必须保留当前 ReportSession 的证据、修正、冲突、验证、追问、复核、确认与不可变快照链。自动测试需覆盖真实工作流行为，而不仅是 JSON 形状。合成案例只证明本地流程，不证明 SBS 现场准确率。最终验收检查 `npm run check`、新增针对性测试、可见界面流程、Git 状态及远端分支 SHA；不把未跟踪的 `video-deliverables/` 混入交付。

本轮不对接 SBS 内部 API、不导入其全部既有维修历史、不承诺无限期保存、不自动诊断或决定车辆可恢复运行、不直接合并 `main`。保存期限、备份、身份与权限、SBS 回写字段与接口需在真实部署前由 SBS 确认；本轮可做可审查的本地持久化与导出，不以此冒充生产部署。
